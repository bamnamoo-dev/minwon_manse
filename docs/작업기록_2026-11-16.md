## 2. 담당자가 정한 것 (다음 작업에서도 지킬 것)

| 주제 | 결정 |
|---|---|
| 사용 환경 | 창구에서 민원인을 앞에 두고 **PC**로 사용. 휴대폰은 후순위. 가장 많이 찾는 민원: 학생(생활기록부·재학·졸업) |
| 디자인 | 포털(aisen.kr) 컨셉. 단계는 두 단이 아니라 한 줄로 |
| 졸업증명서 나이스 발급 | 생활기록부·재학증명서와 **같은 방법**(매뉴얼에 전용 화면 없음 → 재학증명서 화면을 참고로 표시) |
| 나이스·학교증명발급 둘 다 가능한 연도 | **주로 나이스** → 나이스를 먼저 표시 |
| 시스템 화면 연결 범위 | 매뉴얼에 그 증명서 전용 발급 화면이 있는 민원만. **기간형(인허가·신고)·폐지된 학교 증명서(M11~M13)는 연결하지 않음**(학교증명발급시스템에서 발급하지 않음, 모든 민원이 나이스·학교증명발급에서 되는 것 아님) |
| 데이터 표기 | **편람 표기 기준**(예: M78 사무내용 「학원 설립·운영…」) |
| 배포 | GitHub Pages + `minwon.aisen.kr`. 지금은 전부 브라우저에서 처리하므로 서버(VPS) 불필요 — AI 질의응답·의견 받기·접근 제한이 필요해지면 개인 VPS 로 이전, 나중에 aisen.kr 포털에 통합 가능 |
| 주소의 `#` | 그대로 둠(새로고침·즐겨찾기 정상, 검색어가 서버 기록에 안 남음) |
| 디자인 변경 | 시안은 로컬에서 먼저 보여주고 승인 후 푸시(푸시 = 바로 배포) |
