## 2. 알고 있어야 할 원본 데이터 문제

1. **기준은 항상 PDF.** MD 변환본은 병합셀 표에서 칸이 밀리고 글자가 빠짐(예: 「어디나」→「어디서나」 민원처리제)
2. MD에서 14쪽 분량이 통째로 빠짐 → PDF 텍스트로 보충(`pdfTextPages`)
3. 쪽 번호: JSON의 쪽 = PDF 물리 쪽 = 인쇄 쪽 + 10
4. 편람 내부 불일치: 검정고시 무인발급(1978 vs 1983 → 48쪽 표 적용), 재학증명서 정부24(48쪽 표 기준 가능), M61 붙임 서식명 오기, M78 법률명 표기(사무내용 「학원 설립·운영…」/관련근거 「학원의 설립·운영…」 — 편람 그대로)
5. 구비서류 목록이 편람에 없는 민원 18건(주로 법인 공문) — 신청서 이름만 넣음(`npm run validate` 경고)

|---|---|
| `npm run dev` | 개발 서버 http://localhost:5173 |

## 5. 다른 AI 에이전트가 지킬 것 (요약 — 자세한 건 AGENTS.md)

1. `source/`는 절대 수정 금지. 민원 내용은 `data/` JSON에서만 읽고 코드에 하드코딩 금지
2. **편람에 없는 내용을 지어내지 말 것** — 모르면 `TODO(검수필요)` 표시 후 사람에게 묻기
3. `"reviewed": true` 데이터는 임의로 바꾸지 말 것(지금은 96건 전부). `npm run extract -- --force` 금지
4. 사용자가 입력한 연도·나이·생년월일은 **브라우저 밖으로 보내지 않기**(URL·localStorage·서버 금지)
5. 검색·판별 로직을 바꾸면 `npm test` 통과 확인
6. 디자인은 포털 컨셉 유지: 남색 띠(`NavyHero`), 흰 패널, 블루 강조, 분류별 색(`src/lib/colors.ts`)
7. **master 에 푸시하면 바로 사이트에 배포됨** — 시안은 로컬 커밋으로 보여주고 승인 후 푸시
