# 데이터 검수 체크리스트

자동 추출 데이터는 **초안**입니다. 아래 순서로 PDF 원본과 대조하고, 끝난 파일은 `"reviewed": true`로 바꿔 주세요.
(`reviewed: true`인 파일은 `npm run extract`를 다시 돌려도 덮어쓰지 않습니다.)

- PDF 쪽 확인: `public/pages/p{쪽}.webp` 또는 `source/민원편람.pdf` (JSON의 `sourcePages` = PDF 쪽 번호, 인쇄 쪽수보다 +10)
- 검증 실행: `npm run validate`
