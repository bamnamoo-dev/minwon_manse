# 데이터 검수 체크리스트

자동 추출 데이터는 **초안**입니다. PDF 원본과 대조하고, 끝난 파일은 `"reviewed": true`로 바꿔 주세요.

- PDF 쪽 확인: `public/pages/p{쪽}.webp` 또는 `source/민원편람.pdf` (JSON의 쪽 번호 = PDF 쪽 = 인쇄 쪽수 + 10)
- 검증: `npm run validate` · 추출 결과 요약: `docs/extract_report.md`
- **md가 아니라 PDF와 대조하세요.** md는 병합셀 표에서 칸이 밀리는 오류가 있고, 14쪽은 내용이 통째로 빠져 있습니다.

## 덮어쓰기 보호 (안심하고 고쳐도 됨)
`npm run extract`를 다시 돌려도 아래 파일은 건드리지 않습니다.
- `"reviewed": true` 인 파일
- 사람이 손으로 고친 파일 (생성 당시 지문 `_genHash`와 내용이 다르면 자동 감지)
- 강제로 다시 만들려면 `py scripts/extract_minwon.py --force` (주의: 수정 내용 사라짐)
